\section{Objetivo de este archivo}

Este documento organiza las variables que se van a usar en la primera etapa del proyecto.
El orden de trabajo queda asi:

\begin{enumerate}[leftmargin=*]
    \item definir variables y construir una base unificada;
    \item limpiar y recodificar;
    \item estimar un modelo MCO como benchmark de propension;
    \item estimar un modelo Probit para la misma variable dependiente.
\end{enumerate}

La variable objetivo inicial sera la propension a consumir marihuana en los ultimos 12 meses.

\section{Reglas de limpieza propuestas}

\begin{enumerate}[leftmargin=*]
    \item Unir la base de consumo con \texttt{personas} y \texttt{d2} usando las llaves equivalentes.
    \item Recodificar variables binarias del cuestionario respetando el diccionario:
    \begin{itemize}[leftmargin=*]
        \item 1 = Si
        \item 2 = No
        \item 9 = No contesta
    \end{itemize}
    \item Revisar si los faltantes en \texttt{consumo\_12m} significan realmente 0 o si deben quedar como NA.
    \item Tratar codigos especiales en precio y cantidad antes de estimar:
    por ejemplo 9, 98, 99 u otros valores de no respuesta si aparecen en la base derivada.
    \item Crear una variable binaria de trabajo:
    \[
        y_i = 1(\texttt{consumo\_12m}_i = 1)
    \]
    dejando como 0 los casos en que se confirme ``No'' y como NA los no contestados o ambiguos.
    \item Para modelos con precio, considerar usar \(\log(\texttt{precio\_compra})\) luego de eliminar valores invalidos.
    \item Para \texttt{d2\_05}, agrupar categorias si la muestra por nivel educativo es pequena.
\end{enumerate}

\section{Hoja de ruta de modelado}

\subsection{Modelo 1: MCO como benchmark de propension}

Primera especificacion recomendada:

\[
    y_i = \beta_0 + \beta_1 \log(precio_i) + \beta_2 edad_i + \beta_3 edad_i^2 + \beta_4 sexo_i + \beta_5 educacion_i + u_i
\]

donde \(y_i\) es una variable binaria de consumo en ultimos 12 meses.
Este modelo se interpreta como un \textit{linear probability model} y se usa como benchmark simple.

\subsection{Modelo 2: Probit de propension}

Segunda especificacion recomendada:

\[
    Pr(y_i = 1 \mid X_i) = \Phi(\alpha_0 + \alpha_1 \log(precio_i) + \alpha_2 edad_i + \alpha_3 edad_i^2 + \alpha_4 sexo_i + \alpha_5 educacion_i)
\]

Este sera el modelo econometrico principal para la primera etapa del proyecto.

\subsection{Nota metodologica importante}

Si \texttt{precio\_compra} sigue siendo demasiado incompleta luego de limpiar, conviene trabajar con dos especificaciones:

\begin{enumerate}[leftmargin=*]
    \item una especificacion de muestra completa sin precio;
    \item una especificacion reducida con precio para explorar sensibilidad o elasticidad.
\end{enumerate}

Eso evita perder demasiada muestra desde el inicio.
