\section{Conclusiones}

\begin{frame}
\frametitle{Hallazgos clave}
\begin{enumerate}
    \item Benchmark MCO/Probit: AUC-ROC = 0.7232 con 4 variables. Referencia sólida.
    \item ML por defecto \textit{no} supera al benchmark con el mismo feature set.
    \item \textbf{GBM tuneado} (4 feat.): AUC = \textbf{0.7278}, F1 = \textbf{0.6129} — tuning necesario.
    \item \textbf{Feature set ampliado} a 16 variables: red social, actitud, PHQ-2, percepción de riesgo, situación laboral.
    \item SHAP sobre modelo ampliado: distribución de importancia más diversificada y económicamente más rica.
    \item Robustez con Y estricta (K\_03=1): relaciones estructurales estables.
\end{enumerate}
\end{frame}

\begin{frame}
\frametitle{Lecciones metodológicas}
\begin{itemize}
    \item La flexibilidad sin regularización introduce varianza que opaca la ganancia de sesgo.
    \item El \textit{tuning} disciplinado importa más que el algoritmo en muestras moderadas.
    \item Ampliar el \textit{feature set} con variables teóricamente justificadas (red social, percepción de riesgo) es complementario al tuning, no sustituto.
    \item La interpretabilidad no es opcional: define qué tan utilizable es el modelo para política pública.
    \item Documentar limitaciones (Y discrepante, submuestra con precio) es parte del trabajo, no un anexo.
\end{itemize}
\end{frame}
